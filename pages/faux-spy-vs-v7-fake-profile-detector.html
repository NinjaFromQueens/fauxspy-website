Why update velocity matters in AI detection

Midjourney has released seven major versions. DALL-E, Stable Diffusion, and Flux have each gone through multiple generations. Each new version produces images that are meaningfully more photorealistic than the last — and each new generation requires detection models to be retrained specifically against those outputs.

V7's fake profile detector extension hasn't documented meaningful updates in the 2025–2026 window during which these generators improved significantly. That's not a criticism of the original product — it was a good tool when it launched. But in a category where the threat evolves with each new AI release, a static model loses accuracy over time.

Faux Spy's detection uses a commercial API that is specifically in the business of keeping up with new generators. Pro subscribers fund that API access, which is why the extension stays current without asking users to do anything differently.

Deepfake detection: the scenario V7 doesn't document

V7's extension was designed around detecting AI-generated profile photos. Faux Spy Pro adds a second detection layer: deepfake identification for photos that are real-but-AI-manipulated. This matters because romance scammers increasingly manipulate real photos of real people rather than generating synthetic faces from scratch.

A real photo manipulated by AI won't trigger a purely generative detection model — it isn't generated, it's altered. Faux Spy Pro's deepfake model looks for the artifacts of that alteration process, not for the signature of generation. Catching both threat vectors requires both models.

When V7's extension might still be useful

If you have V7's extension installed and it's working for your use case, it may still catch some AI-generated images — particularly ones created by older generators. The question is whether you can rely on it for current AI output (Midjourney v7, Flux, DALL-E 3) without documented model updates against those generators.

For casual use where you're not actively trying to catch sophisticated fake profiles, the extension may be sufficient. For anyone seriously evaluating whether a dating profile is real before making an emotional or financial decision, the accuracy gap matters.
